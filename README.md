# -
本项目是一款基于 STM32G431RBT6 微控制器的嵌入式信号控制与监测实战系统。系统通过板载 ADC 采集模拟电压，实现对 PWM 输出频率及占空比的动态精密调节，并利用定时器输入捕获技术完成外部信号的实时频率测量。  系统核心功能包括：  智能调控：支持根据输入电压动态改变 PWM 特性，并提供参数配置界面，满足多种控制需求。 异常监测：具备实时运行状态监控，一旦检测到参数超限（如频率差异常），自动记录故障时刻及系统状态，确保运行可靠。 人机交互：采用多界面 LCD 显示架构（PWM主界面、RECD异常记录、PARA参数配置），配合按键逻辑实现高效的系统管理与界面切换。 涵盖了 ADC、PWM、输入捕获、GPIO、定时器以及 LCD 显示驱动等核心技术。
