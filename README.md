# 嵌入式精密信号控制与监测系统 (Embedded Precision Signal Control & Monitor System)

---

## 🚀 项目概述

本项目基于 **STM32G431RBT6** 微控制器，旨在构建一套高可靠的工业级信号处理系统。系统通过高精度 ADC 采集模拟电压，实现对 PWM 输出的动态精密调节，并结合定时器输入捕获技术，对外部信号频率进行实时监测与异常分析。

该项目应用于需要精密调控 PWM 参数并实时监控系统运行状态的嵌入式工业场景。

## 🛠 技术栈

*   **硬件平台**: STM32G431RBT6 (ARM Cortex-M4)
*   **开发环境**: STM32CubeMX + Keil MDK
*   **核心库**: STM32 HAL Library
*   **外设驱动**: ADC (电压采集), TIM (PWM 输出/输入捕获), GPIO (按键/指示灯), LCD 显示驱动

## ⚙️ 核心功能

1.  **精密 PWM 调控**: 实现频率与占空比的动态闭环调节，支持通过模拟电压输入实时控制。
2.  **实时状态监测**: 持续监测外部信号频率（DF），与设定频率进行比对。
3.  **异常记录与诊断**: 自动捕捉参数超限时刻，记录系统状态（CF, CD, DF, XF）及发生时间，确保问题可追溯。
4.  **模块化交互界面**: 采用多界面架构（主控/记录/参数），实现高效的参数设置与系统监控。

## 💡 技术亮点 (面试点)

*   **架构设计**: 将外设配置与逻辑控制解耦，代码结构清晰，易于维护。
*   **性能优化**: 利用定时器输入捕获与 DMA 等硬件机制，减少 CPU 处理开销，确保高频信号捕捉的实时性。
*   **可靠性设计**: 引入异常检测与状态锁存机制，保障系统在极端参数条件下的稳定性。
