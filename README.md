# 嵌入式精密信号控制与监测系统 (Embedded Precision Signal Control & Monitor System)

---

## 🚀 项目概述

本项目基于 **STM32G431RBT6** 微控制器，构建了一套高可靠的工业级信号处理系统。系统通过 ADC 采集模拟电压，实现对 PWM 输出频率及占空比的动态闭环调控，并结合定时器输入捕获技术，对外部信号频率进行实时高精度监测。

该系统采用了**应用逻辑与底层驱动分离**的架构设计，提升了代码的可维护性与模块化程度，能够稳定应用于精密信号处理与环境状态监测场景。

## 🛠 技术栈

*   **硬件平台**: STM32G431RBT6 (ARM Cortex-M4)
*   **核心库**: STM32 HAL Library
*   **开发环境**: STM32CubeMX + Keil MDK
*   **实现技术**: ADC 数据采集, TIM PWM 输出与输入捕获, GPIO 按键状态处理, 状态机设计

## ⚙️ 核心功能

1.  **动态 PWM 调控**: 实现频率与占空比的实时闭环调节，支持通过模拟电压输入灵活改变输出参数。
2.  **实时状态监测**: 持续采集外部信号频率（DF），基于实时比对算法对系统运行状态进行诊断。
3.  **异常记录与诊断**: 引入异常检测与状态锁存机制，自动捕捉参数超限时刻并记录系统关键状态（CF, CD, DF, XF）及发生时间，确保存储数据的可追溯性。
4.  **模块化交互界面**: 采用多界面架构（主控/记录/参数配置），配合防抖逻辑与状态机实现高效的人机交互。

## 🏗 工程实践

*   **架构解耦**: 通过封装业务逻辑层，将功能控制与硬件外设操作分离，确保了核心控制逻辑的独立性与易移植性。
*   **高性能实现**: 充分利用 MCU 硬件外设（定时器输入捕获、硬件 PWM），极大降低了 CPU 处理频率捕捉任务的开销，确保了高频信号处理的实时性。
*   **规范化开发**: 遵循模块化命名规范与文档标准，提升了复杂嵌入式系统的可读性与后期维护效率。
